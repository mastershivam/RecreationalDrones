This guide follows the ECAA's legislation page and the English text of RPAS Part 106 (Issue 1, Rev. 0, dated March 2026), read on 26 October 2026. Part 106 is an operator standard in the style of ICAO Annex 6. It does not set a registration, fee, minimum age, weight or height limit for a recreational flyer. **Check the ECAA for the implementing instructions**, which the Part says will set the low-risk authorisation or declaration.

## Not covered yet

- **Authorisation or declaration for low-risk flights:** the Part refers to ECAA implementing instructions that we did not find.
- **Fees, minimum age, weight thresholds, height and distance limits, Remote ID, insurance, penalties and visitors:** Part 106 does not state them.
- **Distances from airports and no-fly areas:** none found, so the map draws no circle.
